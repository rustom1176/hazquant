# HazQuant

HazQuant is a hazard calculation and compliance web application, built as a world-class independent implementation inspired by modern hazmat calculation workflows.

## Status
🔨 In Progress

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Prisma + PostgreSQL
- NextAuth/Auth.js
- Vitest + Playwright
